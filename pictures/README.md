# 시노프 사진

이 폴더에 JPG, JPEG, PNG, WebP, AVIF 사진을 넣으세요. 파일명 순서대로 문장 하나를 처음 완성할 때 사진 한 장씩 나타납니다. 파일명은 자유롭게 사용할 수 있습니다. 사진 수보다 완성 문장이 많으면 처음 사진부터 다시 사용합니다.

로컬 미리보기에서는 폴더의 사진을 자동으로 찾습니다. 사진을 넣은 뒤 미리보기를 새로고침하세요. 원본 비율을 유지해 표시하며, 실제 사진이 없을 때는 사진 자리를 비워둡니다.

정적 사이트 배포 전에는 프로젝트 루트에서 `python3 scripts/build-tablet-pictures.py`를 실행해 manifest.json 목록을 갱신합니다. 이 명령은 사진 원본을 수정하지 않습니다.
